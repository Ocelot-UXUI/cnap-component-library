# 2026-08-03

## 容器日志与 Web 终端接口改为 WebSocket

远端 ku 文档更新：查看容器日志和 Web 终端改为 WebSocket 通信。本次仅同步接口文档与 API 层实现，不涉及业务组件 UI 改动。

### 源文档同步

- `docs/input/source-api-runtime-workloads.md`：接口总览表新增两条 WS 路径（`/ws/v1/.../logs`、`/ws/v1/.../terminal`）；查询容器日志章节新增 "WebSocket 模式" 子节；新增 "Web 终端" 章节（含 `v5.channel.k8s.io` 协议说明与 channel ID 表）。

### API 层变更

- `src/api/runtimeLogStream.ts`：从 HTTP fetch + ReadableStream 改为 WebSocket。`buildContainerLogUrl` → `buildContainerLogWsPath` / `buildContainerLogWsUrl`（`/api/cnap/ws/v1/` 前缀）。认证头（`x-region`/`x-account-id`/`baggage`）因 WebSocket 无法设置自定义 header，转为 query 参数传递。`streamContainerLogs` 接口签名不变（params/handlers/controller 保持一致），`useContainerLogStream` hook 无需改动。
- `src/api/runtimeTerminal.ts`（新增）：基于 `v5.channel.k8s.io` 协议的 WebSocket 终端连接。导出 `connectContainerTerminal`（返回 `sendInput`/`resize`/`close` 控制器）、`buildContainerTerminalWsPath`/`buildContainerTerminalWsUrl`。binary frame 首字节为 channel ID（0=stdin/1=stdout/2=stderr/3=error/4=resize），resize payload 为 `{Height, Width}` JSON。
- `src/api/runtimeLogStream.test.ts`：测试改为验证 `buildContainerLogWsPath`（`/api/cnap/ws/v1/` 前缀）；mock `getCommonOptionsForAppspace` 避免 localStorage 依赖。`createLineAssembler` 测试不变。
- `vite.config.ts`：proxy `/api` 增加 `ws: true`，支持开发环境 WebSocket 代理。

### 未纳入范围

- `ContainerTerminal.tsx` UI 组件实现（xterm.js 终端渲染）—— 接口层已就绪，业务组件待后续实现。
- `ContainerSubTabs.tsx` Props 透传 —— 待终端 UI 实现时一并处理。
- `runtimeResource.ts` 的 `getContainerLogs` HTTP GET 接口保留（远端文档仍列出该端点，用于非流式场景）。
