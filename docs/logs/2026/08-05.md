## 统一剪贴板复制：copy-to-clipboard 替代 navigator.clipboard

- 借鉴 antd `Typography` 的 copyable 实现，新增项目级规范：复制能力统一走 `@/utils/clipboard` 的 `copyText`，禁止业务代码直接用 `navigator.clipboard`。
- 变更：
  - `package.json`：新增依赖 `copy-to-clipboard@^4.0.2`（antd 本已传递依赖）。
  - `src/utils/clipboard.ts`（新增）：`copyText(text, options?)` 委托 `copy-to-clipboard`，**返回 `Promise<boolean>`**（v4 的 `copy()` 异步：优先 `navigator.clipboard`，失败回退 `execCommand`）；支持 `{ format: 'text/html' }`。
  - `src/utils/__tests__/clipboard.test.ts`（新增）：mock `copy-to-clipboard`，覆盖 delegate / format 透传 / 失败 resolve false（均 async）。
  - 改造 3 处调用点：`PodDetailDrawer/detailTables.tsx`（`copyPortAddresses` 改 async）、`Settings/ApiKeysTab.tsx`、`AIChat/MessageActions.tsx`，均 `await copyText(...)`；反馈 `message` 由各调用方自持。
  - `docs/context/conventions.md`：新增 "Clipboard / 复制到剪贴板" 规范条目（含理由与"必须 await、勿用 `if(copyText())`"提醒）。
- 理由：`navigator.clipboard` 仅安全上下文可用，HTTP/iframe/旧浏览器/内网会静默失败；`copy-to-clipboard` v4 带 `execCommand` 回退更稳。注意 v4 `copy()` 已是异步返回 `Promise<boolean>`（v3 为同步 `boolean`），调用方必须 `await`。
- 验证：见本条末尾（依赖未安装，`node_modules` 缺失时补记）。
- 变更未提交，留待用户决定。

## 面包屑上一级切换后自动选中唯一下一级

- 现象排查：面包屑切换应用后环境不自动选中。根因在 `navigationContextReducer.ts` 的 `selectApplication` 分支把 `environmentId` 置空后无任何补选逻辑（`selectAccount` 同理），环境仅能由用户手选或 `deriveRouteContext`（依赖已有 environmentId）填充。属既定行为，非运行期故障。
- 保守策略实现（`navigationContextReducer.ts`）：新增纯函数 `autoSelectSingleChild(context, candidates, from)`——上一级变化后，仅当下一级待选项**唯一**时自动选中，并按 account→application→environment 逐级级联。
  - `selectAccount`：候选 application 唯一则自动选中，再级联到唯一 environment。
  - `selectApplication`：候选 environment 唯一则自动选中；`from='application'` 保证不会反向重选 application（尊重用户对应用的显式选择，含清空）。并显式清空 `clusterId`（环境变更后旧集群失效，与 `selectEnvironment` 一致）。
- 测试：新增 `src/contexts/__tests__/navigationAutoSelect.test.ts`（4 例，直接测纯 reducer `applyNavigationSelection`，内联 candidates 避免网络依赖）：覆盖唯一环境自动选中、多环境不选、切账号唯一应用+级联唯一环境、多应用不选。
- 验证：`yarn lint-type` 通过（0 error）；`yarn eslint` 改动文件 0 error/0 warning；`yarn vitest run navigationAutoSelect` 4/4 通过。既有 `navigationContextMachine.test.ts` 仍因 `loadNavigationContextCandidates()` 走真实网络返回 401 而整套 skip（改动前即如此，与本次无关）。
