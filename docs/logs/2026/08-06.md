# 2026-08-06

## Workspace Keep-Alive P0（一级路由工作台状态保持）

- 背景：一级路由（workspace）间来回切换时，子路由页面全部重挂、状态丢失。根因为 `WorkspaceContentLayout` 的 `RoutedContent key={pathname}` + 单一 `<Outlet/>`。
- 方案：内容区与路由分支解耦，基于 React 19.2 `<Activity>` 落地「每工作区常驻 Pane + cached outlet」模型。owner doc：`docs/architecture/workspace-keep-alive.md`；plan：`docs/plans/2026-08-06-workspace-keep-alive-p0-plan.md`。
- 变更：
  - Add `src/routers/lazyPages.ts`、`withSuspense.tsx`、`routePattern.ts`、`workspaceRoutes.tsx`（按 workspaceKey 分区的 RouteObject 表 + FULL_BLEED_PATHS）。
  - Add `src/routers/AppLayout/workspace/content/WorkspaceHost.tsx`（Activity 包裹 + 懒挂载已访问工作区 + `/` 重定向 applications）、`WorkspacePane.tsx`（useRoutes + 缓存最近非空匹配元素 + 独立滚动容器）及各自 `.style.ts`。
  - Fix `WorkspaceContentLayout.tsx` 去除 `key={pathname}` 与 `<Outlet/>`，改挂 `WorkspaceHost`，滚动下移到 Pane；`AppLayout/index.tsx` 移除 `pathname` prop。
  - Fix `src/routers/index.tsx` 降级为骨架（`AppLayout` + `{ path: '*' }` 兜底 + `/playground`/`*`）。
- 验证：`yarn lint-type` PASS；`yarn lint` 仅剩既有 `src/utils/i18n/index.ts` 2 处 no-explicit-any error 与既有 max-lines warning（HEAD 基线已存在，非本次引入）；`yarn build` PASS；`yarn verify:router-paths` PASS。`yarn test` 6 个失败文件经 HEAD stash 比对确认为既有失败（401 网络 + derive/navigationTool/usageMerge），非本次回归。
- 待手动验证（P0 Exit）：浏览器内 7 个一级路由切换保持状态/滚动；未访问工作区首挂正常；前进/后退正常。
