## 修复 pre-commit 格式化结果未纳入提交

- 问题：`.husky/pre-commit` 执行 `yarn format`（`dprint fmt` 全量格式化），但格式化后的改动未自动 `git add` 到暂存区，导致提交中代码仍为未格式化版本。
- 修复：安装 `lint-staged`，在 `package.json` 中配置 `*.{ts,tsx,js,jsx,mjs,cjs,json,md}` → `dprint fmt`，将 `.husky/pre-commit` 从 `yarn format` 改为 `npx lint-staged`。lint-staged 只格式化暂存文件并自动重新暂存。
- 同步更新 `docs/context/conventions.md` Git Hook 集成段落。
