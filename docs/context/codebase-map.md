## Large Or Fragile Files

| Path                                | Risk                                | Preferred Approach             |
| ----------------------------------- | ----------------------------------- | ------------------------------ |
| src/executor/AIExecutorProvider.tsx | 核心执行引擎，状态机复杂            | 小步修改，每次仅改一个步骤类型 |
| src/executor/agentLoop.ts           | Agent 循环逻辑，与 SSE 流式响应耦合 | 修改前确保理解流式协议         |
| src/api/ai/chat.ts                  | AI 对话 API，含 mock/prod 模式切换  | 先在 mock 模式下验证           |
| src/contexts/AIChatContext.tsx      | AI 对话全局状态，被多个组件消费     | 优先通过 hooks 层修改          |
| src/routers/index.tsx               | 所有路由集中定义，易改错            | 新增路由优先；避免大规模重组   |

## Project-Specific Search Hints

- Use file patterns: `src/pages/**/*.tsx`, `src/components/**/*.tsx`
- Use content anchors: `useAIExecutor`, `aiProps`, `data-ai-action`, `data-ai-entity`, `AISemanticProps`
- Avoid editing generated files: `/ai-context.json` (generated by `yarn gen:ai-context`)

## Update Rule

Update this file when a change creates a new major entry point, moves common code, or adds a new test location.
