# 工作负载主页面

## 功能模块

### 概览仪表板（Summary Cards）

#### 工作负载统计卡片

- **实例统计**
  - 总实例数：全部 Pod 总数
  - 运行中：状态为 Running 的 Pod 数
  - 异常：状态为 CrashLoopBackOff、Failed、Pending 的 Pod 数
  - 屏蔽中：已屏蔽不接流的 Pod 数

- **资源统计**
  - CPU 总量（单位：vCPU，又称为c）
  - 内存总量（单位：GiB）
  - GPU 卡数：按型号分类（如 A100-40G、H100-80G）

- **部署状态**
  - 部署完成/部署中：显示当前部署状态和图标
  - 最近部署时间：Hover 显示具体时间戳
  - 当前配置版本（v24 格式）：Hover 显示最近修改时间
  - Settings 图标表示配置信息

#### 快速过滤（Quick Filters）

- **全部**：显示所有状态的 Pod
- **运行中**：仅显示 Running 状态的 Pod
- **异常**：仅显示异常状态的 Pod（CrashLoopBackOff、Failed、Pending）
- **屏蔽中**：仅显示已屏蔽的 Pod

#### Pod 操作菜单

- **查看详情**：跳转到 Pod 详情页

- **性能分析**：进入性能监控页面
- **屏蔽**：将 Pod 从负载均衡器中移除

- **删除**：销毁 Pod（强制删除）

- **复选框**：左侧全选/单选 Pod，支持每行独立勾选

  - 屏蔽状态：屏蔽中 / 接流中 / 全部
  - 工作负载：按工作负载类型分组
  - 搜索：按 Pod 名称搜索

- **分页控制**：可配置每页显示数量（默认 20）

### 批量运维操作

#### 应用重启（Restart Dialog）

**触发方式**：顶部"应用重启"按钮

**功能说明**：

- 对选中的集群中的 Pod 工作容器（不含 sidecar）发送 SIGTERM 信号，触发容器重启
- 按部署并发度依次重启 Pod；集群内按可用度控制；多集群并行执行

**配置选项**：

- **环境选择**：prod（生产环境）
- **超时时间**：1~3600 秒，默认 300 秒
- **集群与参数配置**表格
  - **集群**：集群名称 + 供应商 Icon（AWS/GCP/Azure/Aliyun/Tencent）
  - **可用度锁**：PA 锁阈值（只读），Hover 显示说明
  - **最大不可用**：变更过程中不可用 Pod 的最大比例（只读，默认 25%）
  - **最大可超出**：变更过程中允许超出设定容量的最大比例（只读，默认 15%）

**操作流程**：

1. 用户在对话框顶部介绍文字了解功能
2. 选择超时时间
3. 在表格中勾选要操作的集群
4. 点击"发起操作"按钮
5. 系统返回成功/失败提示

---

#### 横向扩缩（Scale Dialog）

**触发方式**：顶部"横向扩缩"按钮

**功能说明**：

- 在保持当前 Pod 配置和规格的前提下，调整集群内 Pod 的数量
- 用于应对突发流量或减少资源成本

**配置选项**：

- **环境选择**：prod
- **集群与参数配置**表格
  - **集群**：集群名称 + 供应商 Icon
  - **当前副本数**：只读，显示当前 Pod 数量（随机模拟数据）
  - **期望副本数**：可编辑数字输入框，默认等于当前副本数
  - **可用度锁**、**最大不可用**、**最大可超出**：同应用重启

**设计细节**：

- 不包含超时时间配置
- 用户需手动调整期望副本数后才能发起操作
- 默认集群列表不选中，需用户手动勾选

---

#### 纵向扩缩（Scale Vertical Dialog）

**触发方式**：顶部"纵向扩缩"按钮

**功能说明**：

- 在保持当前集群 Pod 数量的前提下，调整 Pod 的资源规格（CPU、内存、GPU）
- 用于优化资源配置和成本

**配置选项**：

**CPU 配置**：

- Request（Req）和 Limit（Lim）两行配置
- 各行前带复选框，可启用/禁用该配置
- 每行含数字输入框 + 单位选择器（c/m）
- 单位切换时自动换算（1c = 1000m）
- 行末内联显示当前值（浅色小字）

**内存配置**：

- 同 CPU，单位为 MiB/GiB，自动换算

**GPU 配置**：

- 下拉列表多选，可选型号：H100-80G、A100-40G、V100-32G 等
- 每种型号前带复选框和数量输入框（默认 1）
- 已选型号用品牌色标签展示
- 下方显示当前 GPU 配置（"当前: H100-80G×2, A100-40G×1"）

**集群与参数配置**表格：

- **集群**：集群名称 + 供应商 Icon
- **CPU**、**内存**、**GPU** 列：宽度优化，内联显示当前值
- **可用度锁**、**最大不可用**、**最大可超出**：同应用重启
- 表格行垂直居中对齐所有列元素

**设计细节**：

- Request 和 Limit 各自拥有独立的当前值
- 不包含超时时间配置
- 默认集群列表不选中

### 对话框通用设计

#### 结构

```
┌─────────────────────────────────────┐
│ 标题 (关闭按钮)                      │
├─────────────────────────────────────┤
│ 功能介绍文字（文本，不带灰底）        │
├─────────────────────────────────────┤
│ 超时时间/环境配置                   │
├───────── 分割线 ──────────────────┤
│ 集群与参数配置表格                   │
│ [表格行 1]                         │
│ [表格行 2]                         │
│ ...                               │
├─────────────────────────────────────┤
│ [取消] [发起操作]                    │
└─────────────────────────────────────┘
```

#### 交互细节

- **宽度**：max-w-4xl（应用重启、横向扩缩）/ max-w-6xl（纵向扩缩）
- **集群列表默认不选中**：用户必须手动勾选才能发起操作
- **按钮文案**："发起操作"（统一用语）
- **介绍文字**：font-size sm，无灰色背景，直接使用 text-foreground
- **当前值显示**：浅色小字，内联在输入框右侧或行尾，提高信息密度并保持和谐

#### ResourceField 组件（仅纵向扩缩）

单个资源配置单元格，包含：

- 启用复选框 + 标签（"Req"/"Lim"）
- 数字输入框（min="0"）
- 单位下拉选择器
- 当前值小字显示

## 交互流程

### 应用重启流程

```
用户点击"应用重启"
  ↓
RestartDialog 打开（集群列表默认不选中）
  ↓
用户（可选）调整超时时间
  ↓
用户勾选集群
  ↓
用户点击"发起操作"
  ↓
系统校验（至少选中 1 个集群）
  ↓
发送请求 → 显示 Toast 提示
  ↓
对话框关闭
```

### Pod 表格过滤流程

```
用户选择快速过滤 → 更新 phaseFilter + quarantineFilter
  ↓
OR 用户选择下拉式条件（状态/屏蔽/工作负载）
  ↓
OR 用户在搜索框输入 Pod 名称
  ↓
表格重新计算显示的 Pod 列表
  ↓
重置分页到第 1 页
```

### 单个 Pod 操作流程

```
用户点击某个 Pod 右侧的"· · ·"
  ↓
Dropdown Menu 弹出（屏蔽 / 接流 / 删除 / 详情 / 日志 / 性能）
  ↓
用户选择操作
  ↓
执行对应的 API 调用或页面跳转
  ↓
显示确认或结果提示
```

## 系统约束

### 集群列表

- **默认不选中**：用户必须主动勾选
- **最大操作集群数**：无限制（需后端定义）
- **供应商**：AWS / GCP / Azure / 阿里云 / 腾讯云 / 百度云 / EKS （可复用当前集群资源图标）

### 参数约束

- **超时时间**：1~3600 秒
- **可用度锁**：百分比或小数（只读，由系统决定）
- **副本数**：正整数，建议 1~1000
- **CPU Request/Limit**：正数，支持 c/m 单位，支持切换单位自动换算
- **内存 Request/Limit**：正数，支持 MiB/GiB 单位，支持切换单位自动换算
- **GPU 数量**：正整数，默认 1

### 搜索与过滤

- **搜索范围**：Pod 名称、工作负载名称
- **过滤维度**：状态、屏蔽、工作负载类型
- **分页**：每页 20/50/100 条，可配置

# Pod 详情浮层

## 1. 整体架构

### 1.1 浮层结构

- **打开方式**：右侧滑出抽屉式浮层
- **关闭方式**：点击关闭按钮或按 ESC 键
- **底部遮罩**：半透明遮罩层，可点击关闭浮层

### 1.2 浮层头部信息

- 显示 Pod 名称（使用 monospace 字体）
- 显示所属应用名称和集群名称
- 位置标签：应用 {appName} • 集群 {clusterName}

### 1.3 Pod 级基础信息行

显示以下 Pod 级别的元数据（网格布局，最多 4 列）：

- **状态**：Pod 运行状态徽章 + 就绪容器数/总容器数
- **Pod IP**：Pod 的集群内 IP 地址
- **节点 IP**：Pod 所在节点的 IP 地址
- **版本**：Pod 所属应用的版本号
- **重启次数**：Pod 累计重启次数
- **存活时间**：Pod 从启动到现在的运行时长
- **创建时间**：Pod 的创建时间戳
- **暴露**：Pod 的暴露方式列表（多个值用逗号分隔）

## 2. 容器作用域区

### 2.1 容器选择（横向切换）

- 可横向滚动的容器列表
- 每个容器显示：
  - 容器类型徽章（main/sidecar/init）
  - 容器名称（使用 monospace 字体）
  - 未就绪指示符（对非 init 容器，当 `ready=false` 时显示）

- 点击容器按钮切换到该容器
- 默认选中第一个主容器（index 0）
- 当打开新 Pod 时重置为第一个容器

### 2.2 二级 Tab 导航

为选定的容器提供以下 4 个功能 Tab：

1. **详细信息** - 容器元数据、镜像、资源、配置等
2. **日志** - 容器运行日志查看和分析
3. **终端** - 容器内交互式终端
4. **事件** - Pod 级别的事件日志

- 点击 Tab 切换查看内容
- 默认打开"详细信息" Tab
- 当切换容器时自动重置为"详细信息" Tab

## 3. 详细信息 Tab

### 3.1 容器基础信息

- **运行状态**：容器当前状态（Running/Waiting/Terminated/Completed）
- **就绪状态**：是否就绪（是/否）
- **重启次数**：容器重启的次数（超过 5 次显示警告色）
- **存活时间**：容器运行时长
- **拉取策略**：镜像拉取策略标签（Always/IfNotPresent/Never）

### 3.2 容器镜像信息

- 显示完整镜像地址
- 拉取策略显示为标签

### 3.3 启动命令（如果存在）

- 显示容器的启动命令和参数（合并显示）
- 支持多行显示长命令

### 3.4 资源和网络

- **CPU / 内存用量**：显示当前使用 / 声明量（带单位 'c' 和 'Gi'）
- **GPU**：如果容器配置了 GPU，显示 GPU 模型、规格和数量
- **端口**：容器暴露的端口列表（名称:端口号）

### 3.5 存储挂载（如果存在）

- 显示容器挂载的存储卷列表
- 每个挂载显示：名称、挂载路径、是否只读、来源

### 3.6 环境变量（如果存在）

- 显示容器环境变量列表
- 每个变量显示：名称、值、来源（直接值/ConfigMap/Secret/字段引用）

### 3.7 上一次终止信息（如果存在）

- 仅当容器已重启过时显示
- 显示：退出原因、退出码、启动时间、终止时间

## 4. 日志 Tab

### 4.1 日志来源切换

- **标准输出**：从 stdout/stderr 读取的日志
- **文件**：从指定日志文件读取的日志
- 通过图标按钮切换，放在工具栏最左侧

### 4.2 标准输出模式

- **运行模式**：
  - 当前运行（必选）
  - 上一次运行（容器重启过时可选）

- **排序模式**：
  - 最新的日志（显示最新的日志在底部）
  - 最早的日志（显示最早的日志在底部）

- 暂停/恢复：暂停后停止加载新日志

### 4.3 文件模式

- 日志文件下拉选择框
- 显示文件别名和完整路径
- 下拉框底部有"配置日志文件"入口（跳转到应用设置）

### 4.4 日志搜索

- 实时搜索框，支持不区分大小写的模糊搜索
- 显示匹配日志数量
- 搜索结果高亮显示

### 4.5 日志标记功能

- 标记按钮：在当前日志底部添加红色分隔线
- 快捷键：空格键（当焦点不在输入框时）
- 标记后自动滚动到底部
- 分隔线随日志滚动保持位置

### 4.6 日志工具栏功能

- **暂停/恢复**：控制日志实时更新
- **标记**：在当前位置添加分隔线（快捷键：空格）
- **下载**：导出当前日志为文本文件
- **弹出窗口**：在新浏览器窗口打开日志（无工具栏）
- **全屏**：放大日志查看区域（点击时变为退出全屏）

### 4.7 日志展示

- 每条日志显示：时间戳、日志级别、日志文本
- 日志级别：INFO/DEBUG/WARN/ERROR（不同颜色区分）
- 当日志为空时显示"暂无日志"或"没有匹配的日志"

## 5. 终端 Tab

### 5.1 Shell 类型选择

- **自动选择**（默认）：由系统选择可用的 Shell
- **bash**
- **sh**

### 5.2 终端连接

- 连接按钮：建立与容器的终端连接
- 已连接后显示"已连接"状态标签
- 连接后按钮变为"断开"按钮
- 断开连接清空终端内容

### 5.3 终端交互

- 显示容器提示符：`root@{containerName}:/app#`
- 支持命令输入和执行（使用模拟响应）
- 支持命令历史记录：↑/↓ 键遍历历史命令
- Enter 键执行命令
- 命令输入框显示用户输入

### 5.4 命令支持（模拟）

- `ls` - 列出目录内容
- `pwd` - 显示当前工作目录
- `whoami` - 显示当前用户
- `hostname` - 显示容器名称
- `ps` - 显示进程列表
- `env` - 显示环境变量
- `cat` - 读取文件内容（演示模式）
- `echo` - 输出文本
- `uname` - 显示系统信息
- `clear` - 清空终端
- `exit` - 断开连接

### 5.5 终端工具栏功能

- **Shell 选择**：下拉框选择 Shell 类型
- **连接/断开**：连接或断开容器
- **清屏**：清空终端内容（仅在连接时可用）
- **弹出窗口**：在新浏览器窗口打开终端
- **全屏**：放大终端查看区域

### 5.6 终端展示

- 显示系统消息（连接状态等，灰色斜体）
- 显示用户输入（绿色提示符 + 用户输入）
- 显示命令输出（浅灰色）

## 6. 事件 Tab

### 6.1 事件列表

- 显示 Pod 相关的事件日志
- 表格形式展示，包含列：
  - **时间**：事件发生时间
  - **级别**：事件级别（Normal/Warning/Error）
  - **类型**：事件类型
  - **消息**：事件描述文本

### 6.2 事件过滤

- 按级别过滤事件
- 支持搜索事件关键词

## 7. 全屏功能

### 7.1 日志/终端全屏

- 日志和终端 Tab 都提供全屏按钮
- 全屏模式：显示区域占满整个视口
- 全屏时工具栏保持可见
- 点击全屏按钮再次点击退出全屏

### 7.2 弹出窗口功能

- 日志和终端 Tab 都提供弹出窗口按钮
- 弹出新浏览器窗口（无工具栏、地址栏等浏览器 UI）
- 日志弹窗显示当前日志内容
- 终端弹窗显示当前终端历史

## 8. 交互细节

### 8.1 打开/关闭

- 打开时自动重置为第一个容器和"详细信息" Tab
- 关闭时保留当前选择状态（用于下次打开该 Pod）
- ESC 键快捷关闭
- 点击遮罩关闭

### 8.2 状态保持

- 切换容器时自动跳转到"详细信息" Tab
- 同一容器内切换 Tab 时保持该容器选中
- 日志暂停状态在容器切换时保留

### 8.3 未就绪指示

- 容器按钮上显示红色圆点指示未就绪
- init 容器不显示未就绪指示

## 9. 数据加载

### 9.1 初始加载

- 打开浮层时加载 Pod 基础信息
- 自动获取容器列表和事件列表
- 详细信息 Tab 立即可用

### 9.2 日志加载

- 切换到日志 Tab 时按需加载
- 标准输出模式支持实时更新（暂停状态除外）
- 文件模式按选择的文件加载

### 9.3 事件加载

- 切换到事件 Tab 时按需加载
- 显示 Pod 级别的所有事件
