CNAP 2.0应用列表-需求评审记录

【应用列表】

* 应用列表，点击应用后，默认进入“应用”工作区的当前页；没有当前页时（用户第一次使用），默认进入工作负载页；没有当前环境时，使用prod环境，没有prod环境按照从生产到非生产的顺序，找第一个环境
* 应用卡片上要展现应用描述，去掉警告副本资源利用率那两行

![](https://rte.weiyun.baidu.com/wiki/attach/image/api/imageDownloadAddress?attachId=188dea968d8640cc8697ba8675ba9bca&docGuid=xEYjeb_5mBzltK)
* 环境列出应用的环境，生产到非生产，每组按id升序，点击可直接切换应用+环境
* 标签点击自动进入筛选
* 筛选支持多选
* 最近更新改为“最近变更”，包括生产环境的部署人、时间、环境、变更类型
* 右下角编辑、切换按钮去掉，右上角增加设置icon按钮
* 应用列表页，面包屑导航显示应用选择框，文案提示“请选择应用”
* 应用增加tag，tag由平台生成，显示应用的属性，如负载类型、技术栈



【新建应用】

* “新建应用”和“用模板新建”入口分开，新建应用为主按钮
* 新建应用后，第一页使用名称+图形+描述，后面的步骤上面显示步骤列表
* 新建应用向导用大向导框（800px）



【应用模板】

* 去掉“我分享的”和“分享给我的”
* 分享功能本质为“跨账号引用”
* 引用的模板，模板卡片上增加标记，以及来自账号
* 卡片上收藏点赞等社交功能都去掉
* 卡片上的模板标签去掉
* 模板详情按钮去掉，点卡片进入模板详情
* 创建应用按钮去掉，换成右上角的icon按钮
* 模板使用中文名，不要英文名，id为唯一标识
* 新建模板功能先去掉，默认通过应用创建
* 去掉分享可见范围，创建的模板都是账户级
* 分享模板（到其他账户）功能单独配置
* 去掉官方模板功能，有需求再加
* 应用模板卡片的类型、tag显示跟应用卡片对齐



【应用设置】

* 角色权限功能去掉，统一在账户设置中管理
* 迁移应用功能暂不实现
* 暂停应用功能去掉
* 删除应用支持级联删除，删除框中把所有环境、集群、工作负载、副本数列出
* 删除应用增加二次确认
