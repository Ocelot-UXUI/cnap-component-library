CNAP 2.0页面和导航

# 左侧导航：切换工作场景/功能板块

![](https://rte.weiyun.baidu.com/wiki/attach/image/api/imageDownloadAddress?attachId=41745839d22d477eb4529721198bc6e0&docGuid=9XAABzF7j93gN4)

左侧采用窄边栏，使用图标+简单文字表示。每个图标的概念是一个“工作区”，代表一类工作场景。用户可以在“工作区”之间切换，切回工作区时，依然停留在工作区上次的页面。

左侧“工作区”激活后，工作区内按需决定是否在工作区左侧显示二级导航。

计划设计的工作区及其功能：

- 主页：用户的个人主页，Dashboard作用，作为进入CNAP平台的入口，显示常用应用、需要关注的报警、正在进行的部署等信息。
- -----分隔线-----
- 应用：（What）应用操作台，以应用为维度进行状态查看、配置、管理，解决应用静态定义和查看的需求。
- 环境：（Where）环境管理操作台，分生产环境和测试环境。
- 变更：（Action）发布、变更流程操作台，对一个应用或多个应用进行。
  - 备选名字：发布、变更、交付、部署

- 资源：（Infra）各类外部资源的操作台，目前主要是集群管理，后续可能会增加其他云资源。
- 账户：当前账户级别的设置、管理、杂项功能。
- -----分隔线-----
- 用户个人设置、更新公告等

# 顶部导航：快速切换上下文（账号、应用、环境）

顶部采用3个下拉框，用于快速切换上下文。

- 账户
  - 当前账户（收起时显示）/选择账户（未选择时显示）
  - （搜索框）
  - 我收藏的账户
  - 最近访问的账户（按访问时间倒排）
  - 其他我有权限的账号
  - -----分隔线-----
  - 查看所有账户
  - 申请账户权限
  - 新建账户

- 应用
  - 当前应用（收起时显示）/选择应用（未选择时显示）/所有应用（特殊页面下显示）
  - （搜索框）
  - 我收藏的应用（当前账户下的）
  - 我收藏的应用（其他账户下的，额外显示账户名称）
  - 当前账户下的最近访问应用
  - 当前账户下的其他应用
  - -----分隔线-----
  - 查看所有应用
  - 申请应用权限
  - 新建应用

- 环境
  - 当前环境（收起时显示）/选择环境（未选择是显示）/所有环境（特殊页面下显示）
  - （搜索框）
  - 当前账户或(当前账户+当前应用)下的环境，按照环境类型分组显示；生产级别环境用更醒目效果
  - -----分隔线-----
  - 查看所有环境
  - 新建环境

# 导航切换原则：保持上下文、保持工作区状态

- 左侧导航（工作区）切换：保持当前工作区的页面位置，切换工作区；切回时，回到工作区的上一个页面
- 顶部导航（上下文）切换：保持当前工作区和页面，切换上下文
- 第一次访问（未选择账号/应用/环境的情况）：跳转至对应的账户/应用/环境列表页，让用户选择
  - 或者，有没有更好的交互方式？

- 当前页面不存在某些属性时，隐藏相应的顶部导航
  - 例如，环境工作区的所有页面，顶部导航不显示应用

二级导航可以考虑支持分组：

- 宽版本，每个分组上面显示小标题
- 窄版本，分组直接用分隔线区分

其他设计点：

- 工作区切换按钮上，如果当前工作区有需要处理的信息，则增加红点提示，包括：
  - 事务：有待审批时，增加红点
  - 变更：有进行中的流程时，增加红点

- 应用、环境、变更、资源、账户几个工作区的排序考虑：
  - 按照使用频度：应用 > 环境 > 变更 > 资源 > 账户
  - 按照逻辑：应用 > 环境 > 资源 > 账户 > 变更

- 对于某些功能，需要符合特定前置条件可用的（例如打开某些开关，或者

相比CNAP 1.0的主要变化：

- 按照应用、环境、资源（集群）、账户几个实体，及发布（变更）操作，重新组织一级导航，目前的一级导航对应工作区概念
- 将一些复杂页面（如运行时）的功能拆分到二级导航，减少深度
