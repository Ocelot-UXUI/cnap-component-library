# Feature: 应用列表页面（应用卡片）

> 状态：未完成（待补充）——已澄清搜索/筛选/收藏/分页/卡片布局/表格视图/默认环境/排序/枚举等要点；仍待进一步补充应用无环境展示形态，并将两个临时应用类型枚举替换为后端正式值后进入实现
> 来源：`docs/input/source-meeting-cnap2-CNAP_2.0应用列表-需求评审记录.md` + 页面结构补充说明（2026-08-11）+ `docs/input/source-pm-cnap2-applications-templates-settings.md`（2026-08-14 对齐裁决）
> 路由：`/applications`

## Goal

实现 CNAP 2.0 应用列表页面，以卡片或表格形态展示当前账号下的应用，支持按名称搜索、按应用类型 / 环境 / 用户标签筛选定位应用，并支持进入应用、切换环境、收藏应用等操作。

本文档当前切片覆盖**应用卡片与表格两种展示形态**，以及两种形态共用的筛选、分页和收藏能力；新建应用向导、应用模板、应用设置等页面不在此范围。

## 页面整体结构

| 区域 | 说明 |
| ---- | ---- |
| A. 页头 | 左侧标题"应用列表"；右侧按钮区： "从模板创建" + "创建应用"（主按钮） |
| B. 筛选区 | 按名称搜索；按应用类型（多选）、环境（多选）、用户标签（多选）筛选；（后端筛选逻辑为各条件取交集、同一条件内多选取并集，前端不需要关心） |
| C. 展示形态切换区 | 内容区右侧提供卡片 / 表格两种展示形态切换按钮，默认展示卡片视图；切换不影响当前筛选条件 |
| D. 内容区 | 根据当前展示形态呈现应用卡片列表或应用表格（见 In Scope） |
| E. 面包屑 | 应用列表页面包屑导航显示应用选择框，提示文案"请选择应用"（文案来源为需求评审记录）；交互与 `cnap2-breadcrumb-context-selectors.md`（Draft，待其定稿）对齐 |

> 页头"创建应用 / 从模板创建"仅提供入口按钮（绑定占位事件），对应流程不在本切片（见 Out Of Scope 与 Business Rule 12）。

## 接口与字段映射

### 应用列表接口

应用列表数据来源：

```http
GET /rest/v1/accounts/{accountID}/applications
```

请求参数与用途：

| 参数 | 类型 | 用途 |
| --- | --- | --- |
| `accountID` | `string` | 当前账号 ID；REST 路径中的业务 ID 统一按字符串处理 |
| `keyword` | `string` | 按应用名称模糊搜索，对应 `name`；描述字段 `description` 仅用于展示，不参与接口搜索 |
| `category` | `string` | 按应用分类筛选；多选值使用英文逗号分隔，例如 `microservice,simple_application`；前端透传筛选值，不做大小写转换 |
| `environmentId` | `string` | 按公共环境 ID 筛选；多选值使用英文逗号分隔；与应用环境的 `applicationEnvironmentId` 不是同一 ID 值域 |
| `labelIds` | `string` | 用户标签 ID，多个 ID 使用英文逗号分隔，例如 `7,8` |
| `page` | `int` | 页码，从 1 开始 |
| `pageSize` | `int` | 每页数量，可选值为 `10`、`20`、`50`、`100`，默认按 `10` 请求 |
| `curApplicationId` | `string`，可选 | 当前应用 ID。page=1 时后端查询该应用并插入列表第一条，page>1 时忽略；前端 API 类型已支持，原始接口文档待同步 |

分页响应字段：

| 字段 | 用途 |
| --- | --- |
| `total` | 应用总数，用于分页器 |
| `page` | 当前页码 |
| `pageSize` | 当前页大小 |
| `items` | 当前页应用数据，卡片和表格共用 |

### 应用列表项字段

| 接口字段 | 类型 | 卡片使用位置 | 表格使用位置 / 规则 |
| --- | --- | --- | --- |
| `id` | `string` | 收藏接口的应用 ID、进入应用上下文 | 名称列对应的应用标识 |
| `accountId` | `string` | 当前账号校验 / 应用上下文 | 不单独展示 |
| `name` | `string` | 顶部信息区应用名称 | 名称列主展示值 |
| `displayName` | `string`，可选 | 当前列表不作为应用名称展示字段 | 不作为名称主展示字段 |
| `category` | `string`，可选 | 应用类型标签 | 类型列 |
| `description` | `string`，可选 | 描述区 | 描述列；空值展示 `—` |
| `systemLabels` | `string[]`，可选 | 名称下方系统标签 | 属性列；空值展示 `—` |
| `userLabels` | `ApplicationUserLabel[]`，可选 | 标签区，使用子字段 `id` / `name` | 标签列；空值展示 `—` |
| `environments` | `ApplicationEnvironment[]`，可选 | 环境区，使用子字段 `applicationEnvironmentId` / `environmentName` | 环境列；按接口返回顺序展示 |
| `defaultApplicationEnvironmentId` | `string`，可选 | 点击卡片、名称或空白处进入应用时的入口环境 | 点击名称或整行时使用 |
| `recentChanges` | `ApplicationRecentChange[]`，可选 | 最近变更区，使用首条数据 | 最近生产变更列，使用首条数据 |
| `isCollected` | `boolean`，可选 | 收藏按钮状态 | 操作列收藏按钮状态 |

`ApplicationRecentChange` 首条数据的字段映射如下：

| 字段 | 展示用途 |
| --- | --- |
| `changedBy` | 变更人 |
| `changedAt` | 变更时间，RFC 3339 输入，展示为 `YYYY-MM-DD HH:mm:ss` |
| `environmentName` | 变更所属环境 |
| `changeType` | 变更类型 |
| `applicationEnvironmentId` | 点击该环境变更时用于定位应用环境 |
| `environmentId` | 公共环境 ID，和 `applicationEnvironmentId` 区分 |

上述四个展示字段按 `变更人 · 变更时间 · 环境 · 变更类型` 拼接；对应字段缺失或 `recentChanges` 为空时展示 `—`。

### 筛选项接口

筛选项数据来源：

```http
GET /rest/v1/accounts/{accountID}/applications/filter-options
```

| 响应字段 | 类型 | 用途 |
| --- | --- | --- |
| `applicationCategories` | `string[]` | 应用类型筛选项；后端从当前账号实际使用的 `application_type.category` 去重并按名称升序返回 |
| `environments` | `{ id: string; name: string }[]` | 环境筛选项；`id` 是公共环境 ID，用于列表参数 `environmentId` |
| `userLabels` | `{ id: string; name: string }[]` | 用户标签筛选项；用于生成 `labelIds` 逗号分隔参数 |

无可用筛选项时，对应字段返回空数组。路径参数、查询参数、响应体中的业务 ID 均统一使用字符串。当前原始接口文档的 `accountID`、`environmentId` 参数表仍标注为 `int64`，属于接口文档类型标注与 REST 实际约定不一致，需求与实体模型以字符串为准。

### 收藏接口

收藏和取消收藏分别调用：

```http
POST /rest/v1/applications/{applicationID}/collection
DELETE /rest/v1/applications/{applicationID}/collection
```

- `{applicationID}` 对应列表项 `id`。
- 请求头由接口实现层负责注入，本页面需求不约束注入方式。
- 响应字段 `applicationId` 与 `isCollected` 用于更新当前应用的收藏状态。
- 重复收藏或重复取消收藏均为幂等操作。

## In Scope（当前切片）

### 应用卡片布局

卡片采用纵向分层布局，内容从上到下依次为：

- **顶部信息区**
  - 左侧展示应用图标占位；图标呈方形圆角样式，图标右下角可展示选中态标记
  - 图标右侧展示应用名称，名称右侧紧跟应用类型标签
  - 应用名称下方展示系统标签，多个系统标签横向排列
  - 右侧为操作区，依次提供收藏、复制/另存为应用模板、应用设置等入口；本期未实现的操作保留按钮并绑定占位事件
- **描述区**
  - 位于顶部信息区下方，展示应用描述
- **环境区**
  - 使用“环境”作为区域标签
  - 环境项以横向标签排列，按接口返回顺序展示
  - 超出首行可展示范围的环境通过汇总项折叠，例如 `+2`
- **用户标签区**
  - 使用“标签”作为区域标签
  - 用户标签以带标签图标的彩色标签展示，例如 `ai`、`critical`
  - 用户标签仅展示，不支持点击进入筛选
- **最近变更区**
  - 与上方内容通过分隔线区分
  - 使用单行文本展示 `变更人 · 变更时间 · 环境 · 变更类型`
  - 无最近变更时展示 `—`

卡片整体为圆角边框容器，内部内容按统一间距分层排列；环境、用户标签和最近变更区域横向占满卡片内容宽度。

### 应用卡片展示信息

1. **应用图标**：接口暂无图标字段，先展示占位图标（后续接口补充后再替换）；占位图标使用方形圆角样式
2. **应用名称**：展示 `name`，位于顶部信息区
3. **应用类型**：展示应用类型标签，紧跟在应用名称右侧
4. **系统标签**：平台生成（非用户自定义），展示应用属性（负载类型、技术栈等），展示在应用名称下一行，多个标签横向排列，仅展示、不可点击
5. **应用描述**：展示在顶部信息区下方
6. **环境列表**：以“环境”为区域标签，列出应用的全部环境，按接口返回顺序展示；超出可视范围的环境折叠为 `+N`
7. **用户标签**：以“标签”为区域标签，展示用户自定义标签（`userLabels`）；标签带标签图标和语义色，仅展示、不可点击
8. **最近变更**：取 `recentChanges` 列表**首条**数据拼接展示：部署人 / 变更时间 / 所属环境 / 变更类型，四段以 `·` 拼接；无变更展示 `—`
9. **操作入口**：右上角依次提供收藏、复制/另存为应用模板、应用设置入口；只有收藏操作在本期实现，其他入口绑定占位事件
10. **收藏状态**：由 `isCollected` 决定，通过右上角收藏按钮体现

### 应用表格视图

表格视图与卡片视图使用同一份应用列表数据、筛选条件、分页状态和操作能力。表格按以下顺序展示列：

| 列 | 展示规则 |
| --- | --- |
| 名称 | 展示应用图标占位、应用名称；左侧固定 |
| 类型 | 展示应用类型标签 |
| 属性 | 展示平台生成的系统标签；无值时展示 `—` |
| 描述 | 展示应用描述；无值时展示 `—` |
| 环境 | 展示应用环境列表 |
| 标签 | 展示用户自定义标签；无值时展示 `—` |
| 最近生产变更 | 使用 `recentChanges` 首条数据拼接展示变更人、变更时间、环境名和变更类型；无值时展示 `—` |
| 操作 | 展示收藏 / 取消收藏、应用设置、另存为应用模板等操作入口；右侧固定 |

表格视图规则：

- 名称列固定在左侧，操作列固定在右侧；中间列可随表格宽度滚动。
- 空值统一展示 `—`。
- 表格行中的应用名称、环境和最近生产变更沿用卡片视图对应的跳转逻辑；跳转前先切换当前应用上下文。
- 收藏操作在本期实现；应用设置、另存为应用模板等操作保留入口并绑定占位事件。
- 表格视图与卡片视图切换时不清空或重置当前筛选条件。

### 卡片操作

1. **点击卡片 / 应用名称 / 卡片空白处** → 三处为同一逻辑，均使用 `defaultApplicationEnvironmentId` 进入该应用的工作负载页面。该字段已由后端按照产品规则选取，前端不再次手动选择环境 ID。
2. **点击环境项** → 使用该环境的 `applicationEnvironmentId` 进入对应应用环境的工作负载页面（一次点击同时切换应用与环境）。
3. **收藏 / 取消收藏** → 点击卡片右上角收藏按钮，状态随 `isCollected` 更新，重复操作幂等
4. **交互注意**：点击环境项、收藏按钮时需阻止事件冒泡，避免同时触发卡片点击进入应用（接口文档 2.6 约定）

> 说明（2026-08-11）：卡片上系统标签（平台生成，仅展示）与用户标签并存，二者均不可点击（2026-08-14 对齐裁决：去掉卡片用户标签点击进筛选；系统标签无筛选参数、不可点击）。

## Out Of Scope

- 新建应用向导的流程与页面（"创建应用"按钮仅提供入口）
- "从模板创建"的流程与模板选择页
- 应用模板的卡片形态与模板相关功能
- 应用设置页面的形态与设置项
- 应用工作区的默认落地页规则（"上次访问记录"机制，由独立的工作区需求处理）
- 除"收藏 / 取消收藏"外的应用相关写操作：创建应用、从模板创建、另存为应用模板、应用设置仅实现入口按钮并绑定占位事件，对应具体行为不在本切片

## Main User Flows

1. **浏览与进入应用**：进入应用列表页 → 查看应用卡片（头像 / 名称 / 系统标签 / 描述 / 环境 / 最近变更 / 收藏状态）→ 点击卡片进入应用工作区
2. **按条件定位应用**：在筛选区按名称搜索，或按应用类型（多选）/ 环境（多选）/ 用户标签（多选，可叠加）筛选 → 卡片或表格按条件收敛 → 点击应用进入应用
3. **切换展示形态**：点击卡片 / 表格切换按钮 → 在两种展示形态间切换，筛选条件、分页和当前列表数据保持不变
4. **快速切换应用 + 环境**：点击卡片或表格中的环境项 → 直接进入目标应用的目标环境
5. **收藏 / 取消收藏应用**：点击卡片或表格中的收藏按钮 → 状态切换（`isCollected`），重复操作幂等

## Business Rules

1. **点击卡片进入应用工作区**：默认落地页规则由独立的工作区需求定义，本需求不承载"上次访问记录"逻辑
2. **默认环境**：直接取 `defaultApplicationEnvironmentId`（后端计算，默认即生产环境）；后端保证恒有值，前端不做缺失兜底。进入应用的入口环境一律按该字段取值（点击卡片空白处与点击应用名称使用同一逻辑）
3. **环境展示**：卡片上环境列表按接口返回顺序展示，前端不做分组 / 排序；按环境筛选只收敛应用集合，卡片内环境列表仍按接口直出、不收敛
4. **系统标签**：平台生成（`systemLabels`，字符串数组），展示在应用名称下一行，仅展示、不可点击，用户不可自定义
5. **筛选**：应用类型多选、环境多选、用户标签多选；搜索 + 应用类型 + 环境 + 标签各条件可同时生效；条件之间取交集，同一条件内多选取并集
6. **最近变更内容**：取 `recentChanges` 列表首条，按部署人 / 变更时间 / 所属环境 / 变更类型四段以 `·` 拼接展示，无变更展示 `—`；变更时间按 `YYYY-MM-DD HH:mm:ss` 展示（dayjs）
7. **筛选数据源**：筛选区的应用类型 / 环境 / 用户标签选项由 `GET /rest/v1/accounts/{accountID}/applications/filter-options` 初始化；`applicationCategories` 取应用实际使用的 `application_type.category` 去重后按名称升序，环境与用户标签按 ID 升序；无数据时对应字段返回空数组。`applicationCategories` 值原样透传为 `category` 参数，不做大小写转换。筛选区的环境选项为公共环境（`environments[].id`），与卡片环境列表的应用环境（`applicationEnvironmentId`）为不同 ID 值域——前者仅用于列表筛选参数 `environmentId`，后者用于点击环境项跳转
8. **收藏**：收藏状态由 `isCollected` 决定；收藏 / 取消收藏调用 `POST / DELETE /rest/v1/applications/{applicationID}/collection`，重复操作幂等；收藏按钮点击后按接口返回更新 `isCollected`。请求头注入由接口实现层负责。
9. **ID 字符串约定**：接口响应中的业务 ID（含应用 id、accountId、applicationEnvironmentId 等）统一为字符串
10. **分页**：页码从 1 开始，每页可选 `10`、`20`、`50`、`100` 条，默认按 `pageSize=10` 请求；翻页或筛选条件变化时重新请求
11. **排序与置顶（后端处理）**：列表排序为固定策略，前端不做分组 / 排序。列表接口新增可选参数 `curApplicationId`（当前应用 ID）：page=1 时，后端使用该参数查询应用数据并将结果插入列表第一条；page>1 时该参数被后端忽略。排序分组由后端按「当前应用 > 已收藏 > 有最近使用记录 > 其余应用，组内按最近使用时间倒序」处理（2026-08-14 裁决）
12. **占位入口**：创建应用、从模板创建、应用设置、另存为应用模板等本次不在实现范围内的操作，仅渲染对应入口按钮并绑定占位事件（如 `() => {}`），点击不产生实际跳转 / 弹窗行为（2026-08-14 裁决）

## Roles / Permissions

- 页面不做前端级权限控制，遵循平台既有鉴权与数据接口权限，无额外角色分支。

## Edge Cases

- 应用无环境：卡片不展示环境列表（空态表现待定，见 Open Questions）
- 账号无应用：展示「占位应用」空态
- 有应用但搜索或筛选无结果：展示「没有符合筛选条件的应用」空态
- 应用无描述 / 无系统标签 / 无用户标签：卡片对应区域留空或隐藏；字段缺失统一展示 `—`
- 无最近变更记录（`recentChanges` 为空）：卡片展示 `—`
- 筛选 / 搜索无结果：展示空态
- 收藏接口失败：提示失败并保持原收藏状态，可重试
- 分页边界：当前页超出总页数时回落至末页并重新请求

## Open Questions

- 应用没有任何环境时，卡片上环境区域的展示形态（隐藏 / 空态文案）
- 应用类型临时枚举值：`microservice`=云原生微服务应用、`simple_application`=轻量级后端应用、`__PENDING_AI_INFERENCE__`=AI 模型推理应用、`__PENDING_AGENT_SANDBOX__`=Agent 沙箱应用；后两个值仅为占位值，待后端正式值确定后替换

## Acceptance Criteria

- [ ] 应用列表页按 页头 / 筛选区 / 展示形态切换区 / 内容区 结构组织
- [ ] 页头左侧显示"应用列表"，右侧有"创建应用"（主按钮）与"从模板创建"两个按钮（均为占位入口）
- [ ] 支持卡片 / 表格两种展示形态，默认展示卡片视图，切换时不影响筛选条件
- [ ] 筛选区支持按名称搜索；支持按应用类型（多选）、环境（多选）、用户标签（多选）筛选，各条件取交集、条件内取并集
- [ ] 筛选区的应用类型 / 环境 / 用户标签选项由 filter-options 接口初始化
- [ ] 卡片按顶部信息区 / 描述区 / 环境区 / 用户标签区 / 最近变更区纵向布局
- [ ] 卡片顶部展示图标占位、应用名称、应用类型标签、系统标签；右侧展示收藏、复制/另存为模板、应用设置入口
- [ ] 卡片展示应用描述、环境列表（按接口返回顺序，超出范围折叠为 `+N`）、用户标签（带标签图标）、最近变更（`recentChanges` 首条四段 `·` 拼接，无变更展示 `—`）
- [ ] 表格按名称（左固定）/ 类型 / 属性 / 描述 / 环境 / 标签 / 最近生产变更 / 操作（右固定）顺序展示
- [ ] 表格空值展示 `—`，表格中的收藏操作可用，其他操作入口保留为占位事件
- [ ] 卡片右上角收藏按钮：点击收藏 / 取消收藏，状态随 `isCollected` 更新，重复操作幂等，接口失败提示并保持原状态
- [ ] 应用列表每页可选 10 / 20 / 50 / 100 条，默认显式按 `pageSize=10` 请求
- [ ] 列表排序由后端处理（当前应用置顶），前端仅按接口返回顺序展示
- [ ] 账号无应用时展示「占位应用」；有应用但搜索或筛选无结果时展示「没有符合筛选条件的应用」；当前页超出总页数时回落至末页并重新请求
- [ ] 面包屑导航显示应用选择框，提示文案"请选择应用"
