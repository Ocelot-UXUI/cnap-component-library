# Feature: 应用列表页面（应用卡片）

> 状态：待开发
> 来源：`docs/input/source-meeting-cnap2-CNAP_2.0应用列表-需求评审记录.md` + 页面结构补充说明（2026-08-11）
> 路由：`/applications`

## Goal

实现 CNAP 2.0 应用列表页面，以卡片形态展示当前账号下的应用，支持搜索 / 筛选定位应用，并支持从卡片直接进入应用、切换环境、按标签筛选等操作。

本文档当前切片聚焦**应用卡片展示信息与卡片操作**；新建应用向导、应用模板、应用设置等页面不在此范围。

## 页面整体结构

| 区域 | 说明 |
| ---- | ---- |
| A. 页头 | 左侧标题"应用列表"；右侧按钮区："新建应用"（主按钮）+ "从模板新建" |
| B. 筛选区 | 按名称搜索应用、按应用业务类型、环境、标签进行筛选（多选） |
| C. 展示形态切换区 | 内容区右侧提供卡片 / 列表两种展示形态切换；当前切片实现卡片视图，列表视图留待后续切片 |
| D. 内容区 | 应用卡片列表（当前切片重点，见 In Scope） |
| E. 面包屑 | 应用列表页面包屑导航显示应用选择框，提示文案"请选择应用"，与 `cnap2-breadcrumb-context-selectors.md` 的面包屑交互对齐 |

> 页头"新建应用 / 从模板新建"仅提供入口，向导流程不在本切片（见 Out Of Scope）。

## In Scope（当前切片）

### 应用卡片展示信息

1. **应用名称**
2. **应用描述**：卡片上展示应用描述
3. **环境列表**
   - 列出应用的全部环境
   - 排序：生产 → 非生产分组；每个分组内按环境 id 升序
4. **应用标签（tag）**
   - tag 由平台生成（非用户自定义），展示应用属性，如负载类型、技术栈
5. **最近变更**
   - 展示生产环境的最近变更信息：部署人、变更时间、所属环境、变更类型

### 卡片操作

1. **点击卡片** → 进入该应用（应用工作区），默认落地页规则见 Business Rules
2. **点击环境项** → 直接切换到目标"应用 + 环境"（一次点击同时切换应用与环境）
3. **点击标签** → 自动进入按该标签的筛选（与筛选区联动，筛选支持多选）
4. **设置入口** → 卡片右上角"设置" icon 按钮，进入应用设置

## Out Of Scope

- 新建应用向导的流程与页面（"新建应用"按钮仅提供入口）
- "从模板新建"的流程与模板选择页
- 应用模板的卡片形态与模板相关功能
- 应用设置页面的形态与设置项
- 列表（表格）视图的列定义与交互（展示形态切换按钮存在，列表视图内容留待后续切片）

## Main User Flows

1. **浏览与进入应用**：进入应用列表页 → 查看应用卡片（名称 / 描述 / 环境 / 标签 / 最近变更）→ 点击卡片进入应用
2. **按条件定位应用**：在筛选区按名称 / 描述搜索，或按状态 / 环境 / 标签筛选（多选）→ 列表按条件收敛 → 点击卡片进入应用
3. **快速切换应用 + 环境**：点击某应用卡片上的环境项 → 直接进入目标应用的目标环境
4. **按标签筛选**：点击卡片上的标签 → 自动进入按该标签的筛选结果
5. **进入应用设置**：点击卡片右上角"设置" icon → 进入应用设置

## Business Rules

1. **点击卡片默认落地页**
   - 默认进入"应用"工作区的**当前页**（用户上次停留的页面）
   - 无当前页（首次使用）时，默认进入**工作负载页**
2. **默认环境兜底**
   - 无当前环境时，使用 **prod** 环境
   - 无 prod 环境时，按**生产 → 非生产**顺序取第一个环境
3. **环境排序**：卡片上环境按 生产 → 非生产 分组排列，组内按环境 id 升序
4. **标签来源**：tag 由平台生成，展示应用属性（负载类型、技术栈等），用户不可自定义
5. **筛选多选**：筛选区各条件（类型 / 环境 / 标签）支持多选；点击卡片标签进入筛选后，该标签处于选中态，且可与其他条件叠加
6. **最近变更内容**：展示生产环境的部署人、时间、环境、变更类型

## Roles / Permissions

- 页面不做前端级权限控制，遵循平台既有鉴权与数据接口权限，无额外角色分支。

## Edge Cases

- 无当前页（首次使用）：默认进入工作负载页
- 无当前环境 / 无 prod 环境：按生产到非生产顺序取第一个环境
- 应用无环境：卡片不展示环境列表（空态表现待定，见 Open Questions）
- 应用无描述 / 无标签：卡片对应区域留空或隐藏
- 无生产环境部署记录："最近变更"区域的展示待定（见 Open Questions）
- 筛选 / 搜索无结果：展示空态
- 标签点击进入筛选后切换展示形态（列表视图）：筛选条件保持，列表视图内容留待后续切片

## Open Questions

- 应用没有任何环境时，卡片上环境区域的展示形态（隐藏 / 空态文案）
- 无生产环境部署记录时，"最近变更"区域的展示内容
- "生产 → 非生产"环境分组的具体定义（分组归属、组间顺序）
- 列表（表格）视图的列定义与交互（当前切片不实现）
- 与 `cnap2-breadcrumb-context-selectors.md` 的面包屑应用选择框的职责边界
