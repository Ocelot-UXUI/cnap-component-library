# Feature: 删除部署资源弹窗

> 父需求：`docs/requirements/workloads-page.md`
> **状态：暂不实现（阻塞）**。后端删除部署资源接口尚未提供：触发接口的 operation name、请求参数（targets 结构等）均未确定，`ApplicationUninstall` 对应的 trigger 路径也未在 API 真源文档中给出。待后端补齐接口与参数后再进入实现阶段。本文档保留 UI/交互设计作为实现参考。

## Goal

提供删除应用部署资源的确认弹窗：用户在应用部署管理页面触发后，弹窗展示集群列表（含可用/期望副本数）和风险提示，用户确认后执行不可撤销的删除操作。

## In Scope

- 弹窗布局：标题栏（含风险提示）、操作说明提示区、应用名称确认区、集群选择表格、底部操作栏
- 弹窗尺寸：800px × 616px，Modal
- 标题栏风险提示：明确删除不可撤销
- 操作说明提示区：蓝色 Alert（info 类型）提示操作需要时间
- 应用名称确认：输入框 + 自动检测提示，**必填**，必须与系统检测的的应用名称一致才能提交
- 集群选择表格：Checkbox、集群名称、可用副本数、期望副本数，以平铺列表展示
- 集群数据来源：`GET /rest/v1/application-environments/:appEnvID/clusters`
- 确定按钮：选择集群后可点击
- 提交接口：`runtimeOperationApi.triggerOperation({ capability: 'ApplicationUninstall' })`
- 提交成功后关闭弹窗、刷新列表

## Out Of Scope

- 批量删除多个应用的部署资源（一次只删一个应用）
- 删除操作的回滚/恢复
- 定时删除
- 删除进度追踪/状态轮询
- 删除的审计日志

## Main User Flows

### 流程 1：标准删除流程

1. 用户在应用部署管理页面点击"删除部署资源"按钮
2. 弹窗打开，集群列表加载中
3. 集群列表加载完成，用户查看集群和副本信息
4. 用户输入应用名称作为二次确认（必填，须与系统检测的应用名称一致）
5. 用户勾选目标集群
6. 应用名称正确且至少选择一个集群后，确定按钮变为可点击
7. 用户点击"确定"，按钮进入 loading 态
8. 成功后：弹窗关闭 → 列表刷新 → 成功提示
9. 失败时：弹窗保持打开，展示 Alert 错误提示，已选集群保留

### 流程 2：取消操作

1. 点击取消或关闭按钮 → 弹窗关闭，不执行任何操作

## Business Rules

- **应用名称确认**：必填。输入框提供 placeholder"请补全应用名称"，下方展示系统检测到的应用名供参考。用户输入必须与系统检测的应用名称完全一致，不一致时确定按钮禁用，输入框下方展示内联错误提示"应用名称不正确"
- **集群选择**：至少选择一个集群后确定按钮可用；未选时底部提示"你当前还未选择集群"
- **提交按钮可用条件**：应用名称匹配 + 至少选择一个集群，两者同时满足
- **集群列表为空**：表格展示空状态提示，确定按钮禁用
- **提交幂等性**：loading 期间确定按钮 disabled
- **appEnvID 来源**：由调用方通过 props 传入

## Roles / Permissions

角色/权限对弹窗 UI 无差异化影响。操作权限由后端 API 校验，前端根据后端返回的权限错误码展示 Alert 提示。本需求不涉及前端权限控制逻辑。【待确认】

## Edge Cases

| 状态                | 表现                                            |
| ------------------- | ----------------------------------------------- |
| 集群列表为空        | 表格展示空状态提示，确定按钮禁用                |
| 集群列表 API 加载中 | 表格展示 Spin loading                           |
| 集群列表 API 报错   | 表格展示内联错误提示                            |
| 未选择任何集群      | 底部提示"你当前还未选择集群"，确定按钮禁用      |
| 应用名称输入不正确  | 输入框下方提示"应用名称不正确"，确定按钮禁用    |
| 提交接口报错        | 弹窗保持打开，展示 Alert 错误提示，已选集群保留 |
| 权限不足            | 提交后展示 Alert "无操作权限"提示               |
| 并发提交            | loading 期间确定按钮 disabled                   |

### 触发接口

```ts
import runtimeOperationApi from '@/api/runtimeOperation';

runtimeOperationApi.triggerOperation({
    appEnvID: number,
    capability: 'ApplicationUninstall',
    // operation name 从运行操作列表接口获取
    targets: [
        { clusterId: 'cluster-a' },
    ],
});
```

### API 依赖

| 接口                                                                                     | 用途                                                                                                     |
| ---------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |

| `POST /rest/v1/application-environments/:appEnvID/runtime/operations/:operation/trigger` | 触发删除（capability: ApplicationUninstall）。⚠️ 具体 operation name 与请求参数结构后端尚未提供，接口缺失 |
